缺集管家

欢迎使用缺集管家！

只需三步就能开始：

  1. 到「设置」页填写 MoviePilot 地址和 API Token
  2. 填写你的 strm 文件目录（或 Emby 地址）
  3. 回到这里点「开始扫描」

详细说明见 README 或设置页的提示文字

把当前所有缺的集（未订阅、未忽略的）一次性提交给 MoviePilot。适合想省事的用户。
